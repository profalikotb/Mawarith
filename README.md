# حساب المواريث الشرعية

تطبيق ويب عربي (RTL) لحساب توزيع التركة وفق أحكام المواريث الإسلامية، **بالإطار القانوني المصري للمسلمين افتراضيًا** (قانون المواريث 77/1943 وقانون الوصية 71/1946)، مع محرك قواعد مستقل وقابل للاختبار، وشرح خطوة بخطوة، ومرجع لكل قاعدة، وإيقاف صريح للحالات غير المدعومة بدل القسمة التخمينية.

> نتيجة حسابية مبنية على البيانات المدخلة؛ لا تُعد إعلام وراثة أو حكمًا قضائيًا أو فتوى شخصية معتمدة. التطبيق غير معتمد من الأزهر أو دار الإفتاء أو أي جهة رسمية.

## التقنية
- Next.js 15 (App Router) + TypeScript + React 19، صفحات ثابتة، الحساب كله على جهاز المستخدم.
- المحرك: `src/engine/` — كسور `BigInt` دقيقة بلا أعداد عشرية، مستقل عن الواجهة.
- Excel: `exceljs` (داخل المتصفح). PDF: صفحة تقرير A4 مطبوعة بمحرك المتصفح (عربية صحيحة وقابلة للبحث).
- حفظ محلي بنسخ + حفظ سحابي اختياري عبر Supabase مع RLS.

## التشغيل
```bash
npm ci
npm test          # اختبارات المحرك
npm run dev       # http://localhost:3000
npm run build
npm run docs      # يولّد docs/SUPPORTED-CASES.md و docs/REFERENCES.md من الكود
```

## النشر على Vercel
1. ارفع المستودع إلى GitHub.
2. في Vercel: **Add New → Project → Import** المستودع. الإطار يُكتشف تلقائيًا؛ `vercel.json` يشغّل الاختبارات قبل البناء (فشل أي اختبار يمنع النشر).
3. (اختياري) السحابة: أنشئ مشروع Supabase، نفّذ `supabase/migrations/001_init.sql`، ثم أضف `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` في متغيرات Vercel. فعّل Email OTP في Supabase Auth وأضف نطاق Vercel إلى Redirect URLs. تحقق من العزل بـ `supabase/tests/rls_isolation.sql`.

## بنية المحرك
| الملف | الدور |
|---|---|
| `fraction.ts` | كسور BigInt |
| `rules.ts` | سجل القواعد: المصدر، المادة، الطبيعة (فقهي/تشريعي/إفتائي)، تاريخ التحقق، الحالة، الإصدار |
| `derive.ts` | تحويل بيانات الأسرة إلى أعداد، وكشف «غير المعلوم» |
| `shares.ts` | الفروض، العصبات، الحجب، العول، الرد، المشتركة، العمريتان، الجد مع الإخوة |
| `estate.ts` | ترتيب الحقوق (م 4): التجهيز ← الديون ← الوصايا |
| `wills.ts` | الوصية الواجبة (م 76–78) والاختيارية (م 37، 79) |
| `calculate.ts` | الخط الكامل + توزيع القروش + فحص الاتزان + الحالة |
| `evaluate.ts` | التمييز بين المجهول المؤثر وغير المؤثر، والسيناريوهات |
| `scenarios.ts` | الحمل (م 42) |
| `takharuj.ts` | التخارج (م 48) طبقة منفصلة |
| `parse-text.ts` | استخراج نصي بقواعد ثابتة (بلا ذكاء اصطناعي) — اقتراح يؤكده المستخدم |

## الاختبارات المرجعية
`tests/` — مسائل كلاسيكية (المنبرية، العمريتان، المشتركة، القريب المبارك، الأخ المبارك…) وفتاوى منشورة لدار الإفتاء المصرية في الوصية الواجبة (3228/1981، 219 و520/1955، 526/1957) بروابطها، واختبارات: التركة المستغرقة، تقريب القروش، ثبات النتيجة مع تغيير ترتيب الإدخال، المجهول المؤثر، الحمل، التخارج.
لا تُعتمد حاسبة إلكترونية أخرى مرجعًا للصحة.

## الخصوصية
لا تحليلات، ولا إرسال بيانات، ولا تسجيل للبيانات الحساسة. رؤوس أمان (CSP، منع التأطير). لا روابط عامة للمسائل.
