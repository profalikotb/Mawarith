# دليل الاستخدام المختصر — حساب المواريث الشرعية

## الخطوات
1. **بيانات المسألة**: جنس المتوفى، تاريخ الوفاة (يوم/شهر/سنة)، تأكيد الوفاة وأن المتوفى مسلم. الأسماء اختيارية.
2. **التركة والالتزامات**: الأصول بقيمتها الكاملة وحصة المتوفى فيها، الديون المستحقة له (تدخل إن كانت ثابتة وقابلة للتحصيل)، الديون عليه (تُخصم إن كانت ثابتة)، مؤخر الصداق (لا يُخصم إلا بتأكيد ثبوته)، التجهيز والدفن، الوصايا الاختيارية. أو «الكسور فقط».
3. **حصر الأقارب**: لكل فئة «موجود / غير موجود / غير معلوم». العبرة بالحياة **وقت وفاة المورث**. «غير معلوم» لا يُعامل أبدًا كـ«غير موجود».
4. **المراجعة**: شجرة القرابة، مساعد الاستكمال (يسأل عن المؤثر فقط)، كشف التعارضات، الحالات الخاصة، والتأكيد النهائي.
5. **النتائج**: الحالة، الجدول، المخطط، الشرح خطوة بخطوة، الحمل، مقارنة السيناريوهات، حصص العقار، التخارج، المستندات، الحفظ والتصدير.

## حالات النتيجة
| الحالة | المعنى |
|---|---|
| مكتمل | لا نقص مؤثر ولا حالة توقف |
| مبدئي | معروضة بشرط افتراضات مبينة (نزاع، حمل، جد مع إخوة…) |
| بيانات غير محسومة | تُعرض مقارنة الاحتمالات فقط |
| متوقف | حالة غير مدعومة أو تحتاج متخصصًا؛ يُبيَّن السبب والمطلوب |

## الخصوصية
- الحساب كله في المتصفح. المسودة في `sessionStorage` (تُمسح بإغلاق التبويب).
- «حفظ نسخة» محلي مع سجل نسخ وإصدار القواعد. حذف وتصدير متاحان.
- السحابة اختيارية (Supabase + RLS لكل مستخدم). لا تحليلات، ولا تسجيل للبيانات في السجلات.

## التقارير
- **PDF**: صفحة تقرير A4 → «طباعة / حفظ PDF». النص عربي حقيقي قابل للبحث.
- **Excel**: خمس أوراق RTL: الملخص، الاستحقاقات (كسور + قروش دقيقة)، التركة، الخطوات، الملاحظات.

> نتيجة حسابية مبنية على البيانات المدخلة؛ لا تُعد إعلام وراثة أو حكمًا قضائيًا أو فتوى شخصية معتمدة.
